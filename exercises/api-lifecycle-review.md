# Exercise - API Lifecycle Review

Review a fictional payments API and decide whether it is ready for public beta.

## Inputs

- OpenAPI draft.
- Sandbox credentials.
- Error response catalogue.
- Developer onboarding flow.
- Support runbook.

## Review Questions

- Is the primary developer journey clear?
- Are authentication and authorization explained?
- Are breaking change policies documented?
- Are observability and support paths ready?
- What must be fixed before general availability?
