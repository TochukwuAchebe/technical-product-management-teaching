# Platform Product Interview Guide

## API Product Strategy

- How would you define success for a new API platform?
- How would you prioritize APIs for a developer marketplace?
- How do you balance internal platform needs with external developer experience?

## Architecture And Systems Thinking

- How would you design a multi-tenant developer portal?
- What should happen when a downstream integration fails?
- Which metrics would show platform reliability and adoption?

## IAM And Governance

- How would you design roles and permissions for app registration?
- When would you choose API keys versus OAuth?
- How would you manage deprecation of a high-usage API?

## Product Leadership

- How do you align engineering, security, legal, sales, and support around a platform launch?
- How do you communicate technical risk to executives?
- How do you keep a platform roadmap credible while still moving fast?
